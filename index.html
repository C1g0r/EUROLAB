A comparar os métodos…

Comparação walk-forward: cada chave foi gerada só com concursos anteriores à data avaliada. Foram utilizados os mesmos 250 concursos de avaliação e cinco sementes para cada um dos cinco métodos.

Atenção: o primeiro classificado é o melhor no histórico observado, não o melhor comprovado para o futuro. O resultado pode variar com a amostra e a escolha entre cinco métodos introduz viés de seleção.

Como funciona e quais são as limitações? +

Método 1 — Seletor walk-forward v1.7: compara cinco métodos — aleatório uniforme, frequências altas, frequências baixas, equilibrado e anti-datas. Avalia os 250 concursos mais recentes utilizando, para cada previsão histórica, apenas a janela anterior de 250 concursos. Cada método é avaliado com cinco sementes fixas; a pontuação média corresponde a números acertados + 0,5 × estrelas. A primeira chave é gerada com o método de melhor pontuação observada. Pode mudar quando novos resultados oficiais entram no histórico. Os sorteios finais usam aleatoriedade criptográfica, não as sementes do teste.

Método 2 — Crowd Intelligence: consulta o modelo experimental Crowd v1.4, calibrado com 757 sorteios e avaliado em 301 concursos posteriores. Usa o coeficiente de associação entre a contagem de números de calendário (1–31) e uma razão agregada de vencedores, ponderando os grupos de combinações segundo esse índice. Só utiliza grupos com pelo menos 80 observações; quando é gerada uma aposta por método, evita números ou estrelas em comum. Com várias apostas, garante combinações completas distintas, mas números e estrelas podem repetir-se entre apostas. As estrelas não são classificadas pelo modelo Crowd, sendo sorteadas entre as disponíveis.

Transparência: o indicador Crowd não estima quantas pessoas escolheram uma chave específica nem demonstra que a combinação terá menor probabilidade de dividir prémios. Não usamos um modelo de frequências para prever resultados futuros nem uma taxa de 44,3% como se fosse vantagem de acerto. Se os ficheiros de ambos os modelos não estiverem disponíveis, não há geração de chaves.

Num sorteio justo, cada aposta simples válida tem uma probabilidade de 1 em 139 838 160 de acertar o jackpot. Com N apostas completas distintas, a probabilidade conjunta de jackpot é N em 139 838 160. Os indicadores dos manómetros não alteram esta probabilidade.
